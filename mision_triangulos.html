🔺 Misión Triángulos

Exploración interactiva de la desigualdad triangular y la determinación de triángulos

Autores: Enzo y Alberto · 2° Año Enseñar con Tecnología · ISFDyT N° 24

PARTE A – Condiciones para construir un triángulo

Mové los deslizadores para cambiar las longitudes de los lados a, b y c. El triángulo se dibuja únicamente cuando se cumplen las tres desigualdades simultáneamente.

PARTE B – ¿Dos lados determinan un único triángulo?

Los lados PQ = 7 y PR = 5 permanecen fijos. Mové el ángulo d para observar cómo varía la forma del triángulo y la longitud del tercer lado.

📝 Consignas para los estudiantes (ABP)

A. Exploración de la desigualdad triangular

  1. Dejen inicialmente \(a=5\), \(b=6\), \(c=7\). ¿Se forma un triángulo?
  2. Mantengan \(a=5\) y \(b=6\). Modifiquen \(c\) hasta encontrar un caso en el que ya no se pueda construir.
  3. Busquen una terna en la que la suma de dos lados sea exactamente igual al tercero. ¿Qué sucede con la figura geométrica?
  4. Encuentren tres ternas posibles y tres imposibles. Registren los valores y justifiquen qué condición falla.
  5. ¿Alcanza con comprobar una sola desigualdad? Justifiquen usando los valores de los deslizadores.

B. Exploración de la suficiencia de los datos

  1. Observen la segunda construcción. ¿Qué longitudes permanecen fijas?
  2. Modifiquen el ángulo \(d\). ¿Qué sucede con el tercer lado?
  3. ¿Obtienen siempre la misma figura? ¿Qué dato adicional permitiría determinar una única construcción?

🔒 Cierre y Registro Teórico

En todo triángulo, la suma de las longitudes de dos lados cualesquiera debe ser estrictamente mayor que la longitud del tercer lado:

a + b > c    a + c > b    b + c > a

La igualdad no alcanza: los segmentos colapsan alineados sobre una misma recta y no encierran una región superficial.

Tres lados dados que cumplen las tres desigualdades determinan un triángulo único salvo congruencia. Conocer solamente dos lados, sin fijar el ángulo o la longitud del tercero, no determina una única figura.

⚙️ Comandos para GeoGebra Classic

Si preferís modelizar la actividad en GeoGebra, copiá y pegá estos comandos en la barra de entrada (uno por línea, presionando Enter).

📋 PARTE A – Desigualdad triangular en GeoGebra
// 1. Deslizadores a = 5 b = 6 c = 7 // 2. Vértices y condiciones A = (0, 0) B = (c, 0) xC = (b^2 + c^2 - a^2) / (2*c) cond1 = a + b > c cond2 = a + c > b cond3 = b + c > a posible = cond1 && cond2 && cond3 C = Si(posible, (xC, sqrt(b^2 - xC^2))) triangulo = Polígono(A, B, C) estado = Si(posible, "SÍ: se puede construir", "NO: no se puede construir") // 3. Textos dinámicos info1 = Texto("a + b > c: " + cond1, (1, 8)) info2 = Texto("a + c > b: " + cond2, (1, 7)) info3 = Texto("b + c > a: " + cond3, (1, 6)) info4 = Texto(estado, (1, 5))
📋 PARTE B – Dos lados fijos y ángulo variable
// 1. Deslizador de ángulo d = 45 // 2. Construcción con lados 5 y 7 P = (15, 0) Q = (22, 0) R = (15 + 5*cos(d°), 5*sin(d°)) triangulo2 = Polígono(P, Q, R) tercerLado = Distancia(Q, R) info5 = Texto("DOS LADOS FIJOS: 5 y 7", (14, 9)) info6 = Texto("Ángulo comprendido: " + d + "°", (14, 8)) info7 = Texto("Tercer lado: " + tercerLado, (14, 7))
